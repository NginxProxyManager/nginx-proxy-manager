## O que é um Host 404?

Um Host 404 é simplesmente um host configurado para exibir uma página 404.

Isso pode ser útil quando o seu domínio está listado em mecanismos de busca e você quer
oferecer uma página de erro mais agradável ou informar especificamente aos indexadores de busca
que as páginas do domínio não existem mais.

Outra vantagem de ter este host é poder acompanhar nos logs os acessos a ele e
ver os referenciadores (referrers).
