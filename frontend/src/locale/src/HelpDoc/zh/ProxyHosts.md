## 什么是代理服务？

代理服务是你想转发网络应用的主机。

代理服务可以为没有SSL服务的网络应用提供SSL服务（可选）。

代理服务是Nginx代理管理器的最常见用途之一。

## 可视化 Nginx 配置

**高级**选项卡提供常用代理超时、最大请求体、缓冲和上游 TLS SNI 的结构化设置。这些值会以确定性顺序渲染，并优先于**自定义 Nginx 配置**中的同名指令。

保存前可使用**预览渲染后的配置**检查生成的 server 块和校验诊断。完整预览会在隔离的 Nginx 镜像中验证候选配置；如果引用的证书仍在创建中，或本地 Nginx 二进制不可用，预览会标记为部分校验，请先查看诊断再保存。

请勿在自定义 Nginx 配置中放入凭据、私钥或其他敏感信息。
