## 憑證說明

### HTTP 憑證

使用 HTTP 驗證方式申請憑證時，Let's Encrypt 伺服器會嘗試透過 HTTP（不是 HTTPS！）連線至您的網域；驗證成功後，便會核發憑證。

使用此方式前，您必須為網域建立一個可透過 HTTP 存取、且指向此 Nginx 安裝環境的 _代理主機_。憑證核發後，您可以修改該 _代理主機_，讓 HTTPS 連線也使用此憑證。不過，為了讓憑證能夠續期，_代理主機_ 仍須保留 HTTP 存取設定。

此流程不支援萬用字元網域。

### DNS 憑證

使用 DNS 驗證方式申請憑證時，您需要使用 DNS 服務供應商外掛程式。系統會透過該 DNS 服務供應商在您的網域中建立暫時性的 DNS 紀錄，接著 Let's Encrypt 會查詢這些紀錄，以確認您是網域所有者；驗證成功後，便會核發憑證。

申請此類憑證前，您不必先建立 _代理主機_，也不必將 _代理主機_ 設定為可透過 HTTP 存取。

此流程支援萬用字元網域。

### 自訂憑證

使用此選項，上傳由您自己的憑證授權單位提供的 SSL 憑證。
