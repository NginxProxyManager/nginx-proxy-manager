## O que é uma Lista de Acesso?

As Listas de Acesso fornecem uma lista de bloqueio ou de permissão de endereços IP de clientes específicos, além de autenticação para os Proxy Hosts via Autenticação HTTP Básica.

Você pode configurar várias regras de clientes, nomes de usuário e senhas em uma única Lista de Acesso e depois aplicá-la a um ou mais _Proxy Hosts_.

Isso é mais útil para serviços web encaminhados que não possuem mecanismos de autenticação próprios ou quando você quer se proteger de clientes desconhecidos.
