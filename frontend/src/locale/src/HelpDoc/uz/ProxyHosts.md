## Proxy Host nima?

Proxy Host — bu siz yo'naltirmoqchi (forward) bo'lgan veb-xizmat uchun kiruvchi ulanish nuqtasidir.

U o'zida SSL qo'llab-quvvatlovi bo'lmagan xizmatlaringiz uchun ixtiyoriy SSL terminatsiyasini taqdim etadi.

Proxy Hostlar Nginx Proxy Manager-ning eng keng tarqalgan foydalanish holatidir.
