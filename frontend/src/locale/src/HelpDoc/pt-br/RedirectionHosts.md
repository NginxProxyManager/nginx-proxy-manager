## O que é um Host de Redirecionamento?

Um Host de Redirecionamento redireciona as requisições do domínio de entrada e leva o
visitante para outro domínio.

O motivo mais comum para usar este tipo de host é quando o seu site muda de
domínio, mas ainda existem links de mecanismos de busca ou de outros sites apontando para o domínio antigo.
